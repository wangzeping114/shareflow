# ShareFlow — 开发任务精细化拆解清单

**项目**：ShareFlow 短视频持股分红平台
**技术栈**：.NET 8 + ASP.NET Core Web API + EF Core + PostgreSQL 16 + Redis 7 + Autofac + Quartz.NET + Vue 3.5 + TypeScript + Naive UI + Docker
**拆解视角**：高级工程师 / 架构师
**版本**：v1.0 | 2026-04-26

---

## 架构设计原则

### 后端

| 原则                         | 落地方式                                                                        |
| ---------------------------- | ------------------------------------------------------------------------------- |
| **IoC / DI**           | Autofac 模块化注册，按层分 Module；接口驱动，禁止 new 具体实现                  |
| **工厂模式**           | 平台收益录入策略工厂 `IPlatformRevenueHandlerFactory`，AI Agent 工厂等        |
| **AOP**                | 使用 Autofac Interceptor / ActionFilter 实现权限校验、操作审计、异常处理、日志  |
| **区域上下文**         | `IRegionContext` 注入，所有平台/货币/功能开关统一走上下文，杜绝硬编码 if/else |
| **领域事件**           | MediatR 发布领域事件，解耦跨模块副作用（创建账号、发通知等）                    |
| **幂等性**             | 关键写操作（分红发放、提款审批）带幂等键，防重复提交                            |
| **Clean Architecture** | Api → Application → Domain ← Infrastructure，依赖方向严格单向                |

### 前端

| 原则                 | 落地方式                                                                        |
| -------------------- | ------------------------------------------------------------------------------- |
| **通用组件层** | `components/base/` 封装所有 Naive UI 二次封装组件，业务组件不直接使用原始组件 |
| **业务组件层** | `components/business/` 封装跨页面复用的业务组件                               |
| **组合式函数** | `composables/` 抽取通用逻辑（分页、表单、权限、区域配置）                     |
| **区域感知**   | `useRegion()` composable，前端功能开关/语言/货币统一走该接口                  |
| **API 层统一** | 所有请求经 `http.ts` 统一拦截；响应统一解包；错误统一 Toast                   |
| **权限指令**   | `v-permission="'dividend.write'"` 指令控制按钮级权限                          |

## 关键依赖与风险

| 风险                                 | 影响                   | 缓解措施                                                                                  |
| ------------------------------------ | ---------------------- | ----------------------------------------------------------------------------------------- |
| GPT-4o Vision API 识别精度不稳定     | AI 截图录入准确率低    | ① Confidence 阈值（< 0.8 必须人工确认）② Platform-Aware Prompt 优化 ③ 保留手动录入兜底 |
| 境外实例无法访问境内 API（网络隔离） | 集团总览境内数据不可用 | 降级展示"境内数据暂不可用"，不影响境外功能                                                |
| 合同 PDF 模板法务未及时提供          | 电子签无法生成 PDF     | 开发阶段使用占位模板，预留 `IContractTemplateFactory` 接口，法务文档到位后替换          |
| QuestPDF 签名嵌入排版问题            | 签名位置不准确         | 模板设计阶段预留固定签名区域坐标，不做动态排版                                            |
| 境内实例备案域名未确认               | 境内上线延迟           | 开发与备案并行推进；备案期间可先用 IP 内测                                                |
